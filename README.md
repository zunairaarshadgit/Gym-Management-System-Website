# Rolex Brand Multi-Page Web Interface

A professional, multi-page static website designed to showcase a luxury brand experience. This project emphasizes clean UI/UX principles, utilizing structured HTML5 and custom CSS3 styling to create a premium aesthetic for high-end watch collections.

## Project Scope
The objective of this project was to develop a cohesive frontend for a luxury brand, focusing on layout consistency, navigation flow, and visual appeal. It serves as a comprehensive demonstration of static web development techniques.

## Key Modules
* **Landing Page (Index):** A high-impact entry point featuring the brand's core identity and aesthetic.
* **Product Gallery:** A structured showcase of luxury collections, including specialized sections like the Diamond Series.
* **User Authentication UI:** Professionally designed Login and Registration interfaces to simulate user access flow.
* **Services & About:** Dedicated sections detailing brand heritage, watch maintenance, and customization services.
* **Contact Interface:** A clean layout for user inquiries and professional communication.

## Technical Stack
* **HTML5:** Used for semantic structuring of all web pages and content organization.
* **CSS3:** Employed for advanced styling, including shadow effects, grid layouts, typography management, and responsive elements.
* **Asset Management:** Integration of high-resolution graphical assets to maintain the luxury brand standards.

## Directory Structure
The repository is organized following a standard web development hierarchy:
* `index.html` - Primary landing page
* `gallery.html` - Product showcase
* `login.html` / `registration.html` - User interface modules
* `about.html` / `contact.html` - Informational pages
* `images/` - Directory containing all graphical assets and product photography

## Deployment and Usage
This is a static web project. To view the website locally:
1. Clone or download the repository.
2. Navigate to the root directory.
3. Open `index.html` in any modern web browser.

## Academic Context
This project was developed as part of the CY-107L (Applications of Information & Communication Technologies) curriculum to demonstrate proficiency in multi-page architecture and frontend design.
